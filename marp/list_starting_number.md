# Custom Starting Numbers

Lists can start from any number. Only the first number matters;
subsequent items auto-increment regardless of what you type.

<!-- teaching: the items after the first are numbered 1 on purpose, to show that only the first number counts -->
3. This list starts at three
1. This becomes four <!-- rumdl-disable-line MD029 -->
1. This becomes five <!-- rumdl-disable-line MD029 -->
